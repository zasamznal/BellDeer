# Происхождение графики

Модели и рисунки в `src/assets/` сгенерированы в Higgsfield 20 ноября 2026 года по референсам из корня репозитория, затем сжаты `gltf-transform` (meshopt, текстуры WebP 1024 px). Без этих файлов игра собирается и показывает процедурные модели из `src/render/props.ts` и `src/render/deerModel.ts`.

| Файл | Что это | Как получено |
|---|---|---|
| `axe-hand.glb` | Правая рука с топором | GPT Image 2.6 по концепт-кадру → Meshy Image to 3D, 8 000 треугольников |
| `cards.webp` | 19 рисунков карт, лист 5 × 4 | GPT Image 2.6 по референсу 05, прозрачный фон; разрезан по промежуткам и уложен в ячейки 256 px |
