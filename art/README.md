# Происхождение графики

Модели и рисунки в `src/assets/` сгенерированы в Higgsfield 20 ноября 2026 года по референсам из корня репозитория, затем сжаты `gltf-transform` (meshopt, текстуры WebP 1024 px). Без этих файлов игра собирается и показывает процедурные модели из `src/render/props.ts` и `src/render/deerModel.ts`.

| Файл | Что это | Как получено |
|---|---|---|
| `axe-hand.glb` | Правая рука с топором | GPT Image 2.6 по концепт-кадру → Meshy Image to 3D, 8 000 треугольников |
| `cards.webp` | 19 рисунков карт, лист 5 × 4 | GPT Image 2.6 по референсу 05, прозрачный фон; разрезан по промежуткам и уложен в ячейки 256 px |
| `light-hand.glb` | Левая рука с фонарём | GPT Image 2.6 по референсу 03 → Meshy Image to 3D, 7 000 треугольников |
| `deer.glb` | Звонарь в A-позе | GPT Image 2.6 по листу 04 → Hunyuan3D v3 LowPoly, 7 600 треугольников. Meshy отклонил картинку фильтром безопасности |
| `trap.glb` | Капкан | GPT Image 2.6 → Meshy Image to 3D, 4 000 треугольников |
| `post.glb` | Стойка для бирки, без бирки | GPT Image 2.6 по референсу 03 → Meshy Image to 3D, 2 400 треугольников |
| `bench.glb` | Верстак с наковальней | GPT Image 2.6 по референсу 01 → Meshy Image to 3D, 4 800 треугольников |

Звонарь приходит одной статичной сеткой. Скелет ему строит `src/render/deerRig.ts`: каждая вершина жёстко привязана к одной из 12 костей по её положению в A-позе, поэтому доски не гнутся, а расходятся в суставах.
